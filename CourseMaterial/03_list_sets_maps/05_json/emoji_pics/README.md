# EmojiPics

This folder contains various potential EmojiPics for students to serialize and
deserialize.

## EmojiPic Creation

1. Find a simple JPEG picture (likely a cartoon)
2. Use the `emoji_pics_color_creator.py` script to transform from JPEG to an EmojiPic
    - Script found in `HSIntroToCS/CourseMaterial/03_programming_in_practice/01_emoji_pics/resources/`
3. Copy the output EmojiPic into an new `.txt` file
4. Clean up the output by copying and pasting various pixels/emojis

## EmojiPic Transformation

- Transform from `emoji_pic.txt` -> `emoji_pic.json`
    - Use `emoji_inputter.py`
- Transform from `emoji_pic.json` -> `emoji_pic.txt`
    - Use `emoji_outputter.py`
