## Lesson Plan

This class serves as a bit of a way-point after so much setup. We will assess
and critique someone's TIL entry. Then, we will assess and critique someone's
code. Finally, students are introduced to the long-running "wheaties" problem-
sets and given time in class to start working on them.

### Setup

- `Python String Wheaties` loaded up in Schoology

### Actual Lesson

- Review
    - git
    - remote vs. local
    - commits
- TIL review
    - Importance of TIL
    - Show rubric
    - Examine someone's entry
        - Spin the wheel
        - Compare against rubric
- Code review
    - First set up perms
        - Why "private"?
        - Walk them through giving me access to their repo
    - Examine someone's code
        - Spin the wheel
- Make sure everyone is up and running
- Setup classwork
    - Why wheaties?
        - Long running check to make sure your Python is improving
        - Learning a "language" is hard, so need nightly practice
- Start homework

### Homework

- Do problems 0 - 4 of `Python String Wheaties`
    - For each problem, create a commit
    - Every time create a commit, push it to main so you don't lose your work
