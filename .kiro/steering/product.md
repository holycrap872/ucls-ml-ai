# product.md

This file defines the course's purpose, audience, and structure so agents
can provide contextually appropriate help.

## Course Overview

A full-year high school course teaching Machine Learning and Artificial
Intelligence. Simultaneously serves as an "advanced python" course while
introducing state-of-the-art AI/ML techniques.

## Student Audience

- 10th–12th graders
- Prerequisite: 9th grade "Intro to CS" (minimum) up through AP CS in Java
- Wide skill range within a single section

## Two-Semester Structure

**Semester 1 — Machine Learning** (units 00–05):
- 00: Foundations of Intelligence (Turing, search, chatbots, philosophy of mind)
- 01: SDE Bootcamp (terminal, git, CI/CD, debugging, AI-assisted coding)
- 02: Intro to Data Science (matplotlib, Monte Carlo, randomness experiments)
- 03: Lists, Sets, and Maps (data structures, FSMs, Markov chains, n-grams)
- 04: Learning Machines (Weka, decision trees, PRIMM, teaching unit project)
- 05: Bayesian Learning (probability, namedtuples, blackjack, Naive Bayes)

**Semester 2 — Artificial Intelligence** (units 06–09 + AI-specific units):
- 06: App Development 1 (Pong, git remote, debugging mystery)
- 07: AI in Society (ethics, bias, red teaming, trolley problem, research paper)
- 08: App Development 2 (end-of-year group project, pitch → build)
- 09: Wrapup (film "Her", offboarding)

**Unused/experimental units** (XX_ prefix):
- XX_cognition_and_computing
- XX_evolutionary_algorithms
- XX_neural_networks
